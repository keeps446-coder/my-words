MY WORDS 오프라인 PWA 설치 안내

1. MY_WORDS_PWA 폴더 안 파일과 icons 폴더를 모두 동일한 웹사이트 경로에 업로드하세요.
2. HTTPS 웹 주소로 index.html을 접속하세요. file://로 직접 열면 서비스워커가 작동하지 않습니다.
3. 갤럭시: Chrome에서 사이트 접속 → 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가.
4. 아이폰: Safari에서 사이트 접속 → 공유 → 홈 화면에 추가 → 추가.
5. 온라인으로 처음 한 번 접속하고 설치하면, 이후 단어 데이터와 화면은 오프라인에서도 열립니다.
6. 음성 읽기는 휴대폰에 설치된 영어·한국어 음성 엔진에 따라 다르며, 오프라인 음성팩이 없으면 오프라인에서 읽지 못할 수 있습니다.
7. 기존 HTML에서 저장된 학습 기록은 사이트 주소가 달라지면 자동 이전되지 않습니다. 기존 앱에서 JSON 백업 → PWA에서 복원하세요.
8. PWA의 학습 기록은 각 기기 로컬 저장소에 따로 저장되므로 기기 간 자동 동기화되지 않습니다.
9. 파일을 수정한 뒤 재배포하면 서비스워커 캐시 버전을 올려야 합니다.
